# Decision: Knowledge Management Approach

## Context

The course requires not only software development, but also documentation of the learning process. Practical work is tracked through public GitHub repositories.

## Decision

I will maintain a separate public GitHub repository as my course knowledge base.

The repository will include:

- lecture notes,
- article summaries,
- glossary,
- learning log,
- reflections,
- decision records.

## Reasoning

A separate knowledge base makes the learning process visible and reviewable. It also supports the principle of a single source of truth.

## Consequences

I need to update the repository regularly and keep notes structured rather than scattered.
