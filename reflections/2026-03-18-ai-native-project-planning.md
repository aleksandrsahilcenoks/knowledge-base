# Reflection: AI-Native Project Planning

## Date

2026-03-18

## What I Learned

I learned that modern software project planning is not only about writing a list of requirements. In AI-native development, the developer also creates an environment where AI tools and agents can work within clear boundaries.

This environment includes documentation, tests, repository rules, task tracking, and explicit project-management decisions.

## What Was New for Me

The idea of an engineering harness was new to me. I understood that AI should not be treated only as a chatbot that generates code. It can be part of the development workflow, but only if the repository contains enough structure and constraints.

## What I Need to Understand Better

I need to better understand how detailed AGENTS.md should be and how to balance short instructions with detailed documentation in `/docs`.

## Connection to My Course Project

For my course project, I should prepare the repository before writing too much code. I need to define the project-management approach, create issues, use pull requests, and document rules for development.
