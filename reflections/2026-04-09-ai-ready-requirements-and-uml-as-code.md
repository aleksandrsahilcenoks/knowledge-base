# Reflection: AI-Ready Requirements and UML-as-Code

## Date

2026-04-09

## What I Learned

I learned that requirements for AI agents must be much more explicit than ordinary human-facing requirements.

A human can often ask clarifying questions or use common sense. An AI agent may instead guess, invent missing pieces, or change unrelated parts of the system.

## Most Important Idea

The most important idea is that a requirement should become a contract.

It should include:

- exact behavior,
- constraints,
- BDD acceptance criteria,
- diagrams,
- test expectations,
- pure-function boundaries.

## Connection to My Project

Before asking AI to implement features, I should prepare atomic stories and diagrams. This will reduce hallucinations and make the implementation easier to review.

## Next Step

Define three atomic stories for my project and add them to the project repository as GitHub Issues.
