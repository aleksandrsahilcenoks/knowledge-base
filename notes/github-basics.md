# GitHub Basics

## Summary

GitHub is a platform for hosting Git repositories and collaborating on software projects. It helps developers track project history, review changes, organize tasks, and publish documentation.

## Key Concepts

### Repository

A repository is the central place where a project lives. It contains files, documentation, and version history.

### Commit

A commit is a meaningful checkpoint in the project history. Each commit should describe one logical change.

Example commit message:

```text
docs: add initial knowledge base structure
```

### Branch

A branch allows development to happen separately from the main version of the project.

### Pull Request

A pull request is used to propose, review, and merge changes.

### Issue

An issue is used to track a task, bug, feature, or improvement.

### README

A README explains what the repository is, why it exists, and how to use it.

## Course Relevance

For this course, GitHub is not only a place to store code. It is also a project management environment where practical work can be reviewed through repositories, commits, issues, and pull requests.
