# AGENTS.md

## Summary

AGENTS.md is a repository instruction file for AI coding agents.

It gives agents operational rules: how to build the project, how to test it, what style to follow, what not to do, and where important documentation lives.

## Possible Sections

An AGENTS.md file may include:

- Project overview.
- Technology stack.
- Repository structure.
- Setup instructions.
- Build commands.
- Test commands.
- Coding standards.
- Commit style.
- Security rules.
- Documentation rules.
- Pull request expectations.

## Example Rules

```text
- Follow Conventional Commits.
- Do not hardcode secrets.
- Use .env.template for environment variables.
- Add tests for new logic.
- Keep documentation updated when architecture changes.
```

## Course Relevance

The practical assignment requires writing the first AGENTS.md file for the project repository. This knowledge base keeps notes about why this file matters and how it should be structured.
