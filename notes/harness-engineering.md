# Harness Engineering

## Summary

Harness engineering is the practice of creating a structured environment where AI agents can contribute to software development safely and effectively.

Instead of only writing code manually, the engineer designs:

- constraints,
- rules,
- feedback loops,
- tests,
- documentation,
- architecture boundaries.

## Main Idea

AI agents become more useful when they operate inside a well-defined system. Without such a system, they may create inconsistent code, break architecture, invent nonexistent libraries, or ignore security practices.

## Engineering Harness Components

A good engineering harness may include:

- repository structure,
- tests,
- linting,
- formatting,
- CI checks,
- documentation,
- AGENTS.md,
- security rules,
- architecture decision records.

## Course Relevance

For the practical assignment, creating an engineering harness means preparing the project repository so that both a human developer and an AI agent can understand how to work inside it.
