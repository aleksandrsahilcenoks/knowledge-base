# Modern Software Project Management

## Summary

Modern software project management has moved from heavy upfront planning toward adaptive, transparent, and AI-native workflows.

The lecture describes three important pillars:

1. Agile mindset.
2. Distributed tools and transparency.
3. AI agents and engineering harnesses.

## Agile Mindset

Agile focuses on working software, collaboration, feedback, and adaptation. Planning is still important, but the plan must be flexible enough to change after contact with real users.

## Scrum

Scrum is based on fixed-length cycles called sprints.

Important Scrum elements:

- Product Backlog.
- Sprint Backlog.
- Increment.
- Sprint Planning.
- Daily meeting.
- Sprint Review.
- Retrospective.

## Kanban

Kanban focuses on continuous flow rather than fixed iterations. It uses a board to visualize work and usually contains columns such as:

```text
Backlog → To Do → In Progress → Peer Review → Done
```

Kanban also uses WIP limits to prevent too many tasks from being started at the same time.

## Scrum vs Kanban

Scrum is useful when the team needs structure, roles, and sprint planning.

Kanban is useful when the team needs flexibility, continuous delivery, and visual workflow management.

For a small course project, Kanban or Scrumban may be more practical than full Scrum.

## Single Source of Truth

A project should have one clear digital place where tasks, decisions, documentation, and progress are tracked.

For this course, GitHub can serve as the single source of truth through:

- README files.
- Issues.
- Pull Requests.
- Project boards.
- Documentation in `/docs`.

## AI-Native Project Management

AI-native development requires more than prompts. It requires a structured environment where AI agents can work safely.

Important elements:

- Clear architecture.
- Tests.
- Documentation.
- Machine-readable specifications.
- AGENTS.md.
- Security rules.

## Course Relevance

This lecture explains why the course requires not only code, but also project structure, documentation, issues, pull requests, and AI-agent instructions.
