# Glossary

## Git

A distributed version control system used to track changes in files and coordinate work on software projects.

## GitHub

A platform for hosting Git repositories, collaborating on code, managing issues, reviewing pull requests, and documenting projects.

## Repository

A project space that contains files, history, documentation, and collaboration tools.

## Commit

A saved checkpoint in the history of a repository.

## Pull Request

A request to merge changes from one branch into another. Pull requests are also used for review and discussion.

## Issue

A trackable task, bug report, feature request, or discussion item in a repository.

## Agile

An approach to software development based on iterative progress, feedback, collaboration, and working software.

## Scrum

An Agile framework based on fixed-length iterations called sprints, defined roles, and regular events.

## Kanban

A workflow management method based on visualizing work, limiting work in progress, and improving flow.

## Engineering Harness

A structured development environment that gives humans and AI agents clear constraints, rules, tests, and documentation.

## AGENTS.md

A machine-readable instruction file for AI coding agents working inside a repository.

## Single Source of Truth

A principle according to which important information should live in one authoritative place rather than being scattered across conversations and informal notes.
