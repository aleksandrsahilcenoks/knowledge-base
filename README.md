# Software Engineering Knowledge Base

This repository is my personal knowledge management space for the Software Engineering course 2025–2026.

The purpose of this repository is to document my learning process, collect important concepts, summarize course materials, reflect on project management practices, and maintain a single source of truth for my progress throughout the course.

## Goals

- Track what I learn during the course.
- Summarize key materials and lectures.
- Maintain notes about Git, GitHub, Agile, Scrum, Kanban, AI-native development, and engineering harnesses.
- Record important decisions and reflections.
- Connect theoretical knowledge with the development of my course project.

## Main Sections

### Notes

The `notes/` folder contains structured summaries of lectures, articles, and course materials.

### Reflections

The `reflections/` folder contains personal reflections on what I learned, what was unclear, and how the material connects to my project.

### Decisions

The `decisions/` folder contains short records of important learning and project-management decisions.

### Learning Log

The `learning-log.md` file tracks my progress week by week.
